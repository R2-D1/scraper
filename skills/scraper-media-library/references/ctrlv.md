# CtrlV SVG-ілюстрації

## Призначення

Це окремий source-specific імпортер CtrlV. Він пише стандартні записи ілюстрацій без проміжного intake та без окремих звітів. Результат входить у загальний image export разом з іншими джерелами.

## Запуск

- Увесь актуальний каталог: `pnpm run ctrlv:import -- --all`.
- Окремі позиції: `pnpm run ctrlv:import -- --id <ctrlv-id> [--id <ctrlv-id>]`.
- Команда завантажує каталог, створює статичний SVG, записує стандартні metadata і запускає спільний механізм перекладів.
- Для звичайної підготовки після імпорту використовуй `pnpm run media:prepare:images -- --no-archive`. Не додавай `--clean` без окремого прямого запиту.

## Колекції та розміщення

- Записи живуть у `library/ctrlv/illustrations/<slug>/`.
- Статичний варіант має початковий slug і рівно одну колекцію `ctrlv-illustrations`.
- Колекція має бути зареєстрована як `illustrations` у живому реєстрі колекцій. Не створюй додаткові source-папки або звіти.

## SVG

- Кольори за замовчуванням CtrlV матеріалізуються без зовнішніх CSS variables.
- Статичний SVG отримує локальне блокування CSS animation.
- SVG не повинен залежати від зовнішніх стилів, скриптів або ресурсів.

## Метадані та переклади

- `sourceName` і `authorName`: `CtrlV`; license: `CC0 1.0 Universal`; category: `illustrations`; download source: `ctrlv`.
- Новий запис спочатку має `pending`. Спільний image translation flow читає master-словники, відправляє в DeepL лише відсутні унікальні значення, поповнює словники й переводить запис у `complete`.
- Наявність ключа в master-словнику означає готовий переклад, навіть якщо переклад дорівнює англійському значенню.
- Некорисні або технічно невалідні теги додавай у спільний tag/key blacklist. Чистий emoji `🏛️` уже належить до key blacklist.
- `pending` CtrlV-записи не допускаються у підготовлений export або двомовну базу.

## Відомі особливості каталогу

- Каталог містить два різні SVG з ID `under-construction`. Імпортер мусить зберігати обидва стабільними унікальними slug, не перезаписувати один іншим.
- Частина SVG має animation CSS усередині SVG, решта використовує загальний CSS CtrlV.
- Пробіли перед кореневим `<svg>` допустимі; каталог не можна мовчки фільтрувати через форматування рядка.

## Перевірка пачки

Після повного імпорту перевір `complete`, унікальні media keys, локалізовані name/alt/tags, одну правильну колекцію та відсутність зовнішніх залежностей. Повторний незмінений імпорт має передати в DeepL нуль текстів.
