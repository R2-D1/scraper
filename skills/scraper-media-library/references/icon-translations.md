# Переклади іконок

Заповнюй лише черги поточної колекції. Не використовуй автоматичний перекладач або сторонні довідники; для неоднозначної назви дивись на відповідну іконку.

## Назви

- Черга: `translations/icons/missing-translations/names/`.
- Передавай візуальну суть, а не буквальний набір токенів. Назва коротка, природна, з великої літери, без слів «іконка» чи «зображення».
- Дію називай дієсловом, предмет — іменником. Дефіси й підкреслення перетворюй на природну фразу.
- Видимий стиль додавай у дужках: `filled` — «заповнена», `outline` — «контурна», `solid` — «суцільна», `bold` — «жирна», `light`/`thin` — «тонка», `rounded` — «закруглена», `sharp` — «гостра».
- Бренди, продукти, технології та власні назви залишай в усталеному оригінальному написанні.
- Орієнтир — 2–3 слова; складена назва перекладається як одна цілісна фраза.

## Keys

- Черга: `translations/icons/missing-translations/keys/`.
- Дай один найкращий короткий український відповідник у нижньому регістрі, без крапок, дужок і пояснень.
- Не додавай кілька варіантів: це переклад ключа, не синоніми.
- Бренди, сервіси, фреймворки та звичні неперекладні технічні скорочення залишай в оригіналі.

## Синоніми

- Черга: `translations/icons/missing-synonyms/`.
- Для кожного незмінного ключа створи масив до 20 реальних пошукових варіантів.
- Українські варіанти став першими; далі можна додати близькі семантичні слова, поширені орфографічні та побутові варіанти, а також релевантні англійські запити.
- Орієнтуйся на візуальний контекст іконки. Не додавай далекі абстрактні асоціації або дублікати лише через регістр.
- Не видаляй ключі та не змінюй їх кількість. Однакові масиви для варіантів на кшталт `sofa` і `sofa-2` допустимі.

## Застосування

Після заповнення трьох черг запусти `pnpm run translations:promote-missing`, а потім scoped-оновлення конкретної колекції. Команда просування переносить назви, keys і синоніми у відповідні майстер-словники та очищує черги.
